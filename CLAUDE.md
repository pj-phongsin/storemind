# StoreMind — Claude Code Briefing

## Project Overview
Retail management web app for Australian retail (Uniqlo-style).
Combines Demand Forecasting + AI Workforce Scheduling.

## Tech Stack
- Frontend: ReactJS + Tailwind CSS + Chart.js
- Backend: Node.js + Express.js
- AI/ML: Python + Scikit-Learn + FastAPI
- Database: MySQL
- DevOps: Docker + docker-compose

## Project Structure
- /frontend    → React app
- /backend     → Node.js + Express API
- /ml-service  → Python FastAPI + ML models
- /database    → SQL scripts
